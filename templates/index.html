❓ О настройках

🔢 K — количество чанков

Сколько фрагментов документации будет найдено поиском и передано модели как контекст.

  • 1–3 — быстрый ответ, мало контекста
  • 5–7 — оптимально (по умолчанию 5)
  • 10–20 — больше контекста, но модель может «размазать» внимание

🌡️ temp — температура

Насколько «креативной» будет модель. Выше — больше вариативности, ниже — строже и фактологичнее.

  • 0.0–0.2 — строго по фактам, почти без вариаций (для точных ответов)
  • 0.3–0.5 — сбалансировано (по умолчанию 0.3)
  • 0.7–1.0 — творческий режим, может придумывать

📝 токенов — макс. длина ответа

Максимум токенов, которые модель может выдать за один ответ. 1 токен ≈ 1 слово или часть слова.

  • 512–1024 — краткие ответы
  • 2048 — оптимально (по умолчанию)
  • 4096+ — для развёрнутых ответов

⚡ Максимум слайдера автоматически подстраивается под выбранную модель: локальные Ollama-модели до 16384, облачные API — до указанных провайдером лимитов.

🏷️ Провайдер

Откуда брать модель для ответа. Настраивается на сервере в файле .env.

  • Локальная (Ollama) — ваша видеокарта, свои модели, бесплатно
  • OpenAI / Polza / DeepSeek / OpenRouter — внешние API, нужен ключ в .env
  • Anthropic (Claude) — Claude через API, нужен ключ в .env

🤖 Модель

Конкретная модель выбранного провайдера. Для локального Ollama показываются все установленные модели (кроме nomic-embed-text).

OK — применить выбранную модель к чату.

📊 Статус-бар

🟢 = сервис работает, 🔴 = недоступен.

  • GPU — занято/всего памяти на видеокарте
  • Ollama — запущен ли локальный Ollama
  • Search — работает ли поисковый сервер RAG (pdf-rag)

📁 Проиндексированные файлы

Кнопка 📁 Файлы в панели инструментов открывает таблицу всех документов в базе знаний RAG.

Поиск — фильтрует таблицу по имени файла в реальном времени. Удобно проверить, проиндексирован ли документ, или найти файл по фрагменту названия.

📤 Загрузка документов

Кнопка 📤 Загрузить открывает диалог загрузки нового документа в базу знаний RAG.

Форматы: PDF, DOCX, DOC, TXT, MD, RTF (до 50 MB).

При загрузке файл проверяется по SHA-256 хешу — если такой документ уже есть в базе, дубликат не создаётся.

После успешной загрузки нажмите 🔄 Переиндексировать, чтобы добавить содержимое нового файла в поисковый индекс (создаются векторные чанки и BM25-индекс).

⚠️ VRAM — предупреждение в статус-баре

Если выбранная модель с текущим контекстом не влезает в видеопамять — в статус-баре появляется ⚠️ VRAM.

При наведении — подсказка: сколько VRAM нужно модели и сколько свободно. Если предупреждение активно — возможны тормоза из-за выгрузки слоёв на CPU.

Расчёт приблизительный для Q4-моделей. Облачные провайдеры не проверяются.
